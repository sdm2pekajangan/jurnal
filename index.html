Pengaturan

Hubungkan Google Sheets

Jurnal dikirim lewat Google Apps Script milik Anda. Data tidak lewat server lain.

Cara memasang

  1. Buat Google Sheet baru, lalu buka Ekstensi > Apps Script.
  2. Hapus isi bawaan, tempel kode di bawah, simpan.
  3. Pilih Terapkan > Deployment baru > Aplikasi web. Akses: Siapa saja.
  4. Salin alamat /exec ke kolom di atas.
